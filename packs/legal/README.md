# Legal Pack

변호사/사건/문서/기한/증거 업무를 위한 vertical pack입니다.

## 다루는 업무

- 사건 요약
- 상담 메모 정리
- 소송/기일/마감 체크
- 증거 목록 정리
- 의뢰인 회신 초안

## pack이 책임질 것

- 법률 문서 템플릿
- 사건별 체크리스트
- 기한 경고 표현
- 증거 분류 규칙
- 클라이언트 커뮤니케이션 문구

## 앞으로 들어갈 데이터

- matter / party / chronology / deadline / evidence_index
- court_document / intake_note / memo
- urgency flag
- action log

## 출력 예시

- `기일이 가까워 우선 정리가 필요합니다.`
- `의뢰인에게 사실관계 확인이 한 번 더 필요합니다.`
- `증거 목록을 사건 흐름 순으로 재정리하는 것이 좋습니다.`
