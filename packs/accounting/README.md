# Accounting Pack

회계/세무/장부/증빙/마감 업무를 위한 vertical pack입니다.

## 다루는 업무

- 거래처 문서 정리
- 매입/매출/증빙 누락 체크
- 마감 전 체크리스트
- 세무 일정/기한 알림
- 고객 요청 메일/메신저 초안

## pack이 책임질 것

- 회계 용어집
- 위험도 판단 규칙
- 문서 누락 체크 규칙
- 마감 임박 표현
- 고객 커뮤니케이션 문구

## 앞으로 들어갈 데이터

- receipt / invoice / bank_tx / tax_deadline / filing_status
- entity profile
- period summary
- exception log

## 출력 예시

- `이번 달 누락 증빙이 3개 있습니다.`
- `부가세 신고 전 마감 점검이 필요합니다.`
- `거래처에 재송부 요청 메시지를 보내는 것이 좋습니다.`
